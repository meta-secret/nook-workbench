# Install the Kubernetes console and pin Hive Codex Light

## Outcome

PR 795 was validated on its exact head, squash-merged, and deployed through the
root Taskfile. The production host now supports direct kubectl, Helm, and k9s
operator use over SSH, while Hive workers explicitly use Codex GPT-5.6 with low
reasoning effort.

## Progress

- Installed pinned kubectl v1.36.2, Helm v3.21.3, and k9s v0.51.0 on the
  production node.
- Installed a user kubeconfig whose exec credential helper mints a short-lived
  service-account token through the existing passwordless sudo boundary.
- Removed the earlier persistent admin-certificate kubeconfig during the
  guarded migration; unrelated kubeconfig shapes are preserved.
- Centralized Hive's default model and reasoning effort as `gpt-5.6` and `low`
  and pinned the same values in the Kubernetes deployment.
- Deployed the exact merged state and verified four Hive replicas with all five
  containers ready and zero restarts, plus healthy dispatcher and reaper
  rollouts.

## Implementation problems

- A first operator-console implementation copied the k0s admin client key into
  the user's home directory. Review identified the excessive credential
  lifetime and the migration was replaced with short-lived token issuance.
- The first legacy cleanup predicate was too broad and could have replaced an
  unrelated kubeconfig. The final guard only migrates the exact historical
  one-cluster, one-context, one-user admin shape.
- k9s version output differs from the kubectl and Helm client formats, so the
  pinned-version parser needed a tool-specific contract.

## Decisions

Interactive read-only and diagnostic Kubernetes use may run directly after SSH
with kubectl, Helm, or k9s. Installation, mutation, recovery, and deployment
remain Taskfile-owned. User kubeconfig contains no persistent token, client
certificate, or private key.

Codex's UI label Light is represented by reasoning effort `low`; Hive pins both
the model and effort so worker behavior does not drift with external defaults.

Browser and extension end-to-end repair remained intentionally deferred for a
