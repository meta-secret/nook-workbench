# Completed Neo4j bootstrap secret normalization

## Outcome

Hive bootstrap and recovery now normalize generated and retained Neo4j secret
values and fail closed when required secret or storage checks are unavailable.

## Progress

- Normalized generated and recovered credentials before Kubernetes publication.
- Added fail-closed secret lookup and retained-storage verification.
- Added regression coverage for contaminated retained state.

## Implementation problems

- The production Control Center rollout exposed a trailing newline in a
  recreated client secret. The live value was repaired safely, then the
  bootstrap path was hardened permanently.

## Decisions

- Secret normalization happens at the infrastructure boundary without logging
  values.
- Missing recovery evidence blocks bootstrap rather than rotating blindly.
