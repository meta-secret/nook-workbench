# Delivered Hive attention alerts

## Outcome

Hive now exposes typed, localized, bounded alerts for task failures, dependency
failures and blocking, stale activity, and stuck cancellation. The Control
Center presents them as a severity- and age-ordered accessible attention queue.

## Progress

- Added Rust-owned alert policy and typed observer projections.
- Added schema-7 backfill and maintained task activity timestamps.
- Added exact active-task totals and honest truncation signaling.
- Added responsive Svelte attention states and focused browser coverage.
- Added real Neo4j coverage for dependency propagation and late enqueue.

## Implementation problems

- Review exposed stale dependency reasons, inconsistent multi-query snapshots,
  unbounded graph expansion, and misleading bounded counts. Each was corrected
  before merge and backed by focused regression coverage.

## Decisions

- Alerts remain derived read-only observability state.
- Lifecycle classification and alert wording remain server-owned.
- Management actions remain outside this release.

## Validation

- Nook PR 860 passed source architecture and the full Hive Rust,
  infrastructure, Neo4j, and 10-journey browser gate on its merged head.
- All review conversations were resolved before squash merge.
