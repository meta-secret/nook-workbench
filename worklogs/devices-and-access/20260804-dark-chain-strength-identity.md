# Dark chain-strength identity adaptation

## Plan

[Dark chain-strength identity adaptation](../../plans/devices-and-access/20260804-dark-chain-strength-identity.md)

## Outcome

Replaced the wide identity dashboard composition with a direct dark adaptation of the existing chain-strength experiment. The route now preserves the reference's narrow container, physical-device anchor, rounded identity band, vault rope rows, brace connectors, compact identifiers, selection dimming, and quiet other-device footer.

## Progress

- Mapped the top anchor to one physical device holding distinct local device keys for different virtual identities.
- Mapped rounded tags to virtual identities and labelled each identity-record replication relationship as provider-mounted or local-only.
- Mapped each independent vault row to typed authorization strands reading identity, device key, and passkey access method.
- Added explicit access-method availability so “opens here” and “now” are shown only when both the local device key and an available protector are evidenced.
- Preserved the dark near-black Nook surface and improved secondary evidence contrast.
- Added contained strand scrolling at phone and compact-tablet widths while preventing document overflow.

## Problems and decisions

- The previous POC used chain-strength styling inside a different dashboard template. The correction preserves the actual reference topology instead of borrowing isolated motifs.
- Sync providers remain identity-record mounts, not vault ownership. Vault boxes continue to represent independent DEK grants downstream.
- The fixed identity control is a highlight control, matching the experiment's selection grammar; it does not claim to replace the full working context.

## Validation

- Confirmed no document-level horizontal overflow and no fresh browser console errors.
- Compared the result against the actual chain-strength component and addressed independent layout-review findings.
- Per the exploration hold, no repository formatter, build, test, detector, or validation command was run. No commit, push, or pull request was created.
