# Complete identity lifecycle and authenticated handoff slice

## Outcome

PR 1002 squash-merged the first semantic slice of the restored identity work.
It delivers Rust-owned identity lifecycle invariants, authenticated handoff,
staged Simple-vault genesis, legacy duplicate app-key migration, event-store
integrity, and durable semantic split rules. The full epoch and recovery work
remains preserved in linked successor PR 1008.

## Progress

- Preserved the 5,041-line full-work commit on the remote successor branch
  before reducing the current PR by capability.
- Linked PRs 1002 and 1008 and recorded their ordered ownership in Workbench.
- Kept portable identity validation and migration policy in Rust.
- Added fail-closed staged rebase and authenticated handoff transactions.
- Added marker-aware legacy migration that preserves a pending identity and
  rejects candidate-only app-key overlaps.
- Hardened event persistence against missing, extra, malformed, and mismatched
  index rows.
- Updated Cortex to prohibit deleting, compressing, or disguising completed
  behavior as a PR-size split.

## Implementation problems

- The original size reduction deleted the most important epoch and recovery
  modules. The repair preserved the full implementation remotely and replaced
  line-count optimization with an explicit two-PR capability sequence.
- Review found staged snapshots that could be normalized too broadly. The Rust
  migration now derives allowed legacy components from the staged base.
- Review found orphan event rows and a write-before-index-validation path. The
  cleanup now scans the vault prefix, and saves validate the index before any
  row mutation.
- Twenty-two complete validation cycles were triggered during the PR. Many
  became obsolete after later review feedback. The final cycles used
  review-first polling and canceled stale runs immediately.

## Decisions

- A PR-size limit governs delivery shape, not delivered behavior.
- Multi-PR work must have a remote preservation commit, linked successor PR,
  semantic capability map, shared owner, and ordered completion record.
- Candidate-only identity overlap is never legacy migration input.
- Event cleanup must not trust the index it is repairing.
- Existing review feedback is resolved before waiting on hosted validation.
