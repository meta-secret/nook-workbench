## Decisions

Private data-carrying states enforce local action order; existing runtime authorization and cryptographic checks remain authoritative. Terminal failure uses the existing full vault-session reset, preserving device identity and provider credentials. It does not claim rollback of encrypted cache writes or JavaScript Promise cancellation. Existing explicit Open reloads the chosen vault through Rust validation; no automatic recovery path, storage journal or new trust root is introduced.
