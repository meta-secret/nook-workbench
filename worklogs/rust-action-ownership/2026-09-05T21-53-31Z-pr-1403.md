# Local keyring signing derivation ownership

## Outcome

`DeviceSigningPublicKey` now owns deterministic derivation from validated signing seeds. The keyring module denies homeless functions and focused tests prove invalid seed and wrong-app-key failures preserve protected material.

## Progress

- Moved the private derivation action to its domain owner and adapted all three local callers.
- Replaced the free test helper with a data-carrying fixture.
- Retained four behavior tests and added focused validation-order and nonmutation coverage.
- Merged PR #1403 as `84cafaf0cac092dc85a79d49f5f18fc4a6fa2739`.

## Implementation problems

## Decisions

- Deterministic derivation has no actionable lifecycle stage, so the existing public-key domain type owns it without introducing typestate.
- Public entry signatures, serialization, schema, validation order, and mutation order remain unchanged.
