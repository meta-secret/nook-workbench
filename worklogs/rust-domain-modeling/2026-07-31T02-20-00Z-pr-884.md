# Move remaining TypeScript domain rules into Rust

## Outcome

Merged [Nook PR #884](https://github.com/meta-secret/nook/pull/884). Portable
backup-code extraction, page-field role classification, OAuth origin policy, and
Simple/Sentinel vault host policy now live in `nook-core` with thin
`nook-wasm` exports. Vault secret forms use generated `NookSecretFormFields`
instead of a TypeScript `SecretFormInput` mirror. Durable follow-ups for
content-script and Node host-policy mirrors are recorded in
`.cortex/exec-plans/ts-domain-to-rust-remaining.md`.

## Progress

- Added core modules and behavior tests for backup-code candidates, page-field
  classification, OAuth origin allowlists, and vault host matching.
- Exported companion heuristics and host-policy helpers through
  `nook-wasm` `companion_heuristics`.
- Routed vault-app OAuth origin resolution through the WASM boundary and removed
  the `SecretFormInput` UI bag in favor of generated form fields.
- Updated the secret-type-picker UI demo to exercise login save through the new
  form path.
- Documented remaining content-script / Manifest host-policy mirrors that cannot
  load the full WASM package yet.

## Implementation problems

- Clippy failed on identity-text expansion and doc/markdown style in the new
  field-classification module; fixed with a combined break predicate and
  `WebAuthn` backticks.
- Preflight rejected `Option` absence bags on WASM OAuth/host APIs and authored
  `undefined` / same-arg forwarding in `oauth-origin.ts`. Replaced with
  `isUnsupported` / empty-string sentinels and a direct WASM re-export for the
  preview-host helper.
- First Verify failures were the UI demo contract (AddSecretForm touched without
  a demo update) and then a demo assertion that filtered login rows by full URL
  instead of `websiteHost` / account text.

## Decisions

- Keep backup-code and password-form heuristics available from core/WASM, but
  leave content-script call sites on TypeScript mirrors until a tiny companion
  WASM or background classify path exists (full package is too large for every
  page).
- Keep Manifest/Node `simple-vault-target` synchronous TypeScript until Node
  WASM init is acceptable for build tooling.
- Outcome/workflow TypeScript remains transport envelopes over generated
  verdict types; no further DTO mirror removal was required in this slice.
