# Complete Cortex skill authority migration

## Outcome

PR [#1170](https://github.com/meta-secret/nook/pull/1170) merged as
`ad83f2bf0438e157c53d6eb2f00e8c29bbc6753e`.

Cortex team documents are the sole semantic authority for project skills.
Harness-specific skill mirrors, TOML team-agent profiles, and the external
skill registry are removed. Loom retains deterministic capabilities and audits.

## Progress

- Removed tracked `.agents/skills`, `.cursor/skills`, and `.claude/skills`
  project mirrors.
- Removed `.codex/agents` TOML profiles and `skills-lock.json`.
- Preserved executable article, audit, expert, and workflow mechanics in Loom.
- Routed hosted `.github/prompts/**` changes through repository policy.
- Added deterministic scans that reject retired skill roots in active agent
  inputs.
- Preserved team ownership and harness-neutral subagent delegation contracts in
  Cortex.

## Implementation problems

- Exact-head review found that hosted prompts were readable by the semantic
  audit but did not trigger the repository policy workflow. SRE added path
  routing and AI added a recursive authority scan.
- Complete validation exposed the newly yanked transitive crate
  `chacha20 0.10.1` already present on `main`. AI advanced only that lock entry
  to non-yanked `0.10.2`; the fresh dependency-policy run passed.

## Decisions

- Team-owned Cortex Markdown owns semantic instructions.
- Loom owns deterministic executable mechanics and validation.
- Harness adapters may route agents but must not duplicate semantic prompts.
- Gizmo owns cross-team integration, review closure, PR readiness, and merge.
