  authenticity values, timestamps, generated honeypot suffixes, and external

  confirmed existing production detection and filling behavior is correct.
- Used one browser-boundary case because the domain behavior is already covered
  by the DOM simulation; browser coverage proves extension integration without
  duplicating the provider matrix.
