# Remove Redis from hosted Rust builds

## Outcome

Hosted Rust and WASM builds now use dependency-fingerprinted GitHub Actions
BuildKit caching without Redis credentials or compiler secret mounts. Pull
request 805 was squash-merged, and the first merged Main run successfully
published both native and WASM dependency caches to the new immutable scope.

## Progress

- Removed the Redis password secret from hosted Bake and Rust compiler stages.
- Added an immutable v4 dependency scope derived from manifests, lockfiles,
  compiler images, Bake files, Cargo configuration, and relevant Taskfiles.
- Kept older cache generations as read-only migration fallbacks while exporting
  only the new fingerprinted generation.
- Added preflight invariants that reject compiler secret mounts, hosted Redis
  credential plumbing, incomplete fingerprint inputs, and unsafe release
  checkout ordering.
- Made release builds fingerprint the requested source while using current
  workflow tooling from an isolated checkout.

## Implementation problems

- Mutable cache scopes restored only a fraction of dependency stages, so
  unchanged dependencies were repeatedly compiled.
- Review found that the initial release ordering fingerprinted workflow source
  instead of requested release source, and later found two missing fingerprint
  inputs. The release checkout order and fingerprint contract were corrected
  before merge.
- The optional extension suite failed with the same sixteen tests as the
  preceding Main baseline. The matching baseline established that failure as
  unrelated; the final exact-head core checks passed without repeating the
  thirty-minute optional suite.

## Decisions

- Hosted delivery has one Rust dependency cache mechanism: BuildKit's GitHub
  Actions backend. Redis remains only as explicit local/runtime tooling.
- Secret contents are not used as cache keys, but secret mounts are forbidden
  in compiler stages to keep the hosted cache boundary stable and auditable.
- A genuinely changed dependency fingerprint gets one cold seed build; future
  builds with the same inputs restore the immutable published scope.

## Validation

- Focused preflight tests passed, including 23 combined cache and release
  isolation cases.
- Preflight clippy, rustfmt, repository formatting, and resolved Bake graph
  checks passed.
- Repeated local BuildKit solves restored native and WASM cargo-chef dependency
  stages as cached without a Redis credential.
- Final exact-head PR run 30251134232 passed native Rust, WASM, verify, preview,
  and applicable checks.
- Merged Main run 30252352302 published the native dependency cache in 14m21s
  and the WASM dependency cache in 6m07s using fingerprint
  `c97c25e23a3babbb9f6410d0db179a81d5ab5e429f367298404388831cf11f82`.
