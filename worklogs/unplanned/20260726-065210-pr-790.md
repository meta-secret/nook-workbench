# Remove scheduled nightly checks

## Outcome

Removed the scheduled nightly live-sync GitHub Actions workflow and its
nightly-only repair prompt. The manual live-provider validation path remains
available through the PR E2E workflow.

## Progress

- Deleted `.github/workflows/e2e-nightly.yml` and the nightly CI-fix prompt.
- Removed the retired nightly Task targets and updated repository documentation.
- Kept manual live sync explicitly pinned to the GitHub provider.
- Added cancellation-safe cleanup that deletes the run-scoped repository under
  the PAT-authenticated account.
- Added repository invariants covering the retired schedule and retained manual
  path.

## Implementation problems

  preflight test; the loop was replaced with a direct assertion.

  the surviving manual path: explicit provider selection, cancellation-safe
  cleanup, and cleanup under the PAT owner's login. Each finding was fixed,
  replied to, and resolved before merge.

## Decisions

- Other scheduled maintenance workflows remain unchanged.
- Real-provider live sync is manual-only and continues to use run-scoped
  repositories with best-effort cleanup.
