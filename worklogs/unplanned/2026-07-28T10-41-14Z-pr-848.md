# Split extension autofill domains

## Outcome

Squash-merged Nook PR 848. The former 2,254-line autofill content script is now
a 151-line scanner and entry point over nine focused domain modules. Every
authored source file in the extraction is below 500 lines.

## Progress

- Extracted login and passkey actions, authenticator actions, login-save
  lifecycle, runtime message routing, widget shell, widget rendering, and
  widget positioning.
- Replaced mutable module globals with domain-owned scan, widget, save-offer,
  and picker state stores.
- Injected only the narrow scan scheduling capability needed by the save
  lifecycle.
- Preserved immediate clearing of login passwords and authenticator codes.
- Extended the existing save-login demo to assert the offer, evidence, and
  commit handoff order across extracted domains.

## Decisions

- Keep page scanning and content-script activation in the entry point.
- Keep the state module dependency-free and make every other dependency edge
  one-way.
- Export only capabilities consumed by another extracted domain.
- Split by runtime responsibility rather than line count or numbered parts.
