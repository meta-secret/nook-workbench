# Complete extension TypeScript API discipline slice

## Outcome

Merged the first rollout slice for strict TypeScript API discipline. The
browser extension now uses one-parameter functions, named typed object
arguments, and concrete domain values across reusable libraries, content,
popup, background, offscreen, scripts, and e2e support.

Shared ESLint analysis, executable fixtures, preflight contracts, and durable
guidance prevent regression. Generic external-value bags are prohibited in
domain and application APIs. Structural external values remain only as private
untrusted-ingress details that narrow immediately into concrete domain types.

## Progress

- Migrated the complete browser-extension slice and adjacent Rust/WASM domain
  boundaries needed to preserve validation ownership.
- Hardened Loom and Nook named-argument analysis against spreads, projections,
  callbacks, class fields, inline methods, and static array accessors.
- Added regression coverage for credential cleanup and provider-import session
  cancellation.
- Stabilized concurrent preview deployment by preparing the pinned deployment
  tool before parallel deploys.

## Implementation problems

- Review-driven analyzer probes found multiple static value-flow bypasses. Each
  was reproduced as an executable fixture before the analyzer was extended.
- A private external boundary model initially risked becoming generic domain
  vocabulary. Guidance and enforcement now explicitly prohibit that use.
- Concurrent cold deployment processes raced while installing their tool. One
  pinned prewarm now completes before the parallel deployment fan-out.
- The final callback-projection fix crossed the 1,000-line source limit. The
  implementation was tightened and preflight confirmed the hard limit.

## Decisions

- Generic values do not model product domains and are prohibited in domain and
  application APIs.
- Untrusted browser or JSON ingress may use a private structural representation
  only long enough to validate and narrow into a concrete domain type.
- Roll out enforcement slice by slice. Extension is complete; smaller web
  packages precede the main application and shared vault UI.
- Keep domain validation and security-sensitive state transitions in Rust/WASM.
