# Split vault app shell domains

## Outcome

Squash-merged Nook PR 849. The former 1,443-line vault application shell is now
a 957-line composition root over four cohesive UI modules for the header,
authenticated workspace, access gate, and dialogs.

## Progress

- Kept lifecycle, routes, extension handoff, and onboarding orchestration in
  the application composition root.
- Extracted header navigation and theme controls into a focused header module.
- Extracted unauthenticated vault access and passkey overlay composition.
- Extracted authenticated secrets, settings, administration, onboarding, and
  bottom-navigation composition.
- Extracted enrollment, sync, replacement, and security dialogs.
- Added a teardown contract so an editor interrupted by Help navigation or a
  vault lock cannot leave parent mobile spacing stale.

## Decisions

- Split by cohesive UI responsibility, not by line ranges.
- Keep secret-editor state local to its authenticated workspace and expose only
  the narrow open-state capability needed for outer-shell spacing.
- Synchronize the outer-shell mirror on every editor transition and component
  teardown.
