# Complete vault Rust WASM boundary refactor

## Outcome

PR 808 moved vault domain state and decisions out of the Svelte facade and
behind typed Rust/WASM APIs. TypeScript now remains responsible for browser
lifecycle and UI reactivity instead of duplicating policy, identifiers, state
machines, recovery summaries, or provider normalization.

## Progress

- Moved Sentinel genesis status, arguments, deliveries, participant summaries,
  existing-vault recovery summaries, recovery connectivity, and block-reason
  decisions into `nook-core` and exposed them through typed WASM bindings.
- Replaced stringly typed vault and password identifiers with Rust-backed
  `StoreId` and `PasswordEntryId` types throughout the affected web components.
- Removed abandoned class members, pass-through action wrappers, JSON
  stringify/parse cloning, duplicated undefined initializers, and the exposed
  promise-chain implementation.
- Enabled Knip unused-class-member analysis across the entire web workspace and
  added preflight ownership checks that prevent domain identifiers and state
  from drifting back into TypeScript.
- Updated `.cortex` architecture guidance and dynamic skills with the ownership
  rules established by this refactor.

## Implementation problems

- Review found raw English Sentinel phase labels. Rust now returns translation
  keys, with the corresponding English and Russian catalog entries.
- Review found that remote recovery could bypass explicit confirmation. The
  decision now belongs to Rust policy, is exposed through WASM, and is covered
  across all connectivity variants.
- Final review found component props that widened Rust-owned domain IDs back to
  strings. The components remain domain-typed and preflight detects future
  widening, including switching-state identifiers.
- The standalone preflight crate requires its own formatting check. Formatter
  and semantic-detector corrections were applied before the final exact-head
  validation.

## Decisions

- Rust/WASM owns portable business rules, domain enums, domain structs,
  identifiers, and validation. Svelte owns only reactive presentation and
  browser lifecycle.
- Optional reactive state uses the type's optional form without duplicating an
  explicit `undefined` initializer.
- Serial storage operations use an encapsulated queue abstraction rather than
  exposing promise rejection swallowing in the vault facade.
- Compatibility behavior and wire payloads were preserved while changing the
  internal ownership boundary.
