# Split web E2E helper domains

## Outcome

Squash-merged Nook PR 846. The former 3,719-line web E2E helper monolith is now
a 15-line compatibility facade over ten domain modules. Every authored module
is below 1,000 lines; the largest is the 808-line local-sync capability.

## Progress

- Extracted vault setup and runtime behavior.
- Extracted GitHub sync, local remote, and multi-device enrollment capabilities.
- Extracted app-log evidence, settings/authentication, provider fixtures, and
  secret operations.
- Added a dependency-neutral environment owner for timeouts, repo identity, and
  dotenv initialization.
- Preserved existing scenario imports through the facade.

## Decisions

- Split by test-domain responsibility rather than arbitrary file parts.
- Keep environmental constants outside mutually dependent helper domains.
- Preserve the app-root `.env.test.local` lookup after nesting the modules.
- Keep existing test consumers stable while allowing new tests to import narrow
  capabilities directly.
