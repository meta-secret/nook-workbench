# Rust-first vault application refactor

## Outcome

Squash-merged Nook PR 900. Rust now owns the portable password-generation,
application, provider, synchronization, conflict, collection, and localization
contracts covered by this refactor. Browser lifecycle and presentation code is
organized into focused TypeScript/Svelte modules.

## Progress

- Deleted the TypeScript password generator and application-kind modules.
- Replaced portable TypeScript sync unions and inline domain collection records
  with generated Rust/WASM contracts.
- Grouped application, authentication, Google, iCloud, enrollment, extension,
  runtime, content, and vault responsibilities into cohesive directories.
- Generated 1,639 reusable translation-key constants from the Rust locale
  catalogs for Rust and TypeScript callers.
- Added enforcement for locale parity, generated drift, raw canonical lookup
  literals, browser message literals, domain mirrors, and source size.
- Addressed every review finding and resolved all six conversations.

## Implementation problems

- Main advanced during the password-generator phase; the branch was updated and
  exact-head validation was repeated.
- An early lifecycle pass moved reactive browser orchestration too far into
  Rust. Review led to a responsibility-based split that kept portable vocabulary
  in Rust and browser queues in TypeScript.
- The localization migration exposed dynamic key construction, browser message
  boundaries, TypeScript enum-initializer limitations, and a serialized demo
  closure that could not capture imported constants. Explicit maps, typed
  boundaries, const-value unions, and an evaluate argument resolved those cases.
- Source-size enforcement required extracting the enrollment rendering view into
  a cohesive module.

## Decisions

- Rust owns portable policy and domain state; TypeScript/Svelte owns browser
  lifecycle, external SDK adaptation, and presentation.
- Locale catalogs remain Rust-owned while deterministic generated constants are
  consumed directly on both sides of the WASM boundary.
- Frontend-only browser and landing message catalogs use dedicated typed
  TypeScript registries.
