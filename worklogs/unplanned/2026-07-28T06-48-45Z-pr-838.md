# Refactor multi-device domains and colocate unit tests

## Outcome

Squash-merged Nook PR 838. Multi-device authorization and Sentinel share
protocol responsibilities now live in cohesive production modules with their
unit tests inline. The obsolete external Rust unit-test file was removed, and
every resulting Rust module remains below 1,500 lines.

## Progress

- Extracted device-access and self-roster policy into `multi_device/access.rs`.
- Extracted Sentinel share issuance and reconstruction into
  `multi_device/sentinel.rs`.
- Kept shared multi-device orchestration in the parent module.
- Colocated each behavior-focused unit test with the implementation that owns
  the behavior.

## Implementation problems

- The first formatter-owned compile pass exposed imports that belonged in the
  new Sentinel module.
- The second pass exposed access-policy imports required by the Sentinel test
  module. Both dependency boundaries were made explicit before the final push.

## Decisions

- Split by authorization policy and Sentinel protocol ownership, not by line
  count.
- Preserve inline Rust unit tests as part of each focused abstraction.
