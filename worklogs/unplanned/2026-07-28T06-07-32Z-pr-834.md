# Split popular-login fixture generators

## Outcome

Squash-merged Nook PR 834. The two oversized popular-login generator scripts
are now small orchestration entry points over cohesive fixture-data,
known-shell, primary-corpus, secondary-corpus, and filler modules. Every
resulting authored JavaScript module is below 1,000 lines.

## Progress

- Extracted reusable fixture data and shell builders.
- Grouped site definitions by corpus responsibility rather than arbitrary
  numbered fragments.
- Preserved generator output and successfully executed both entry points.

## Implementation problems

- The first exact-head run found one destructured parameter that became unused
  after extraction.
- A direct host lint attempt was unavailable because the disposable worktree
  did not contain installed web dependencies. The full GitHub Verify lint found
  the issue, which was removed before the second push.

## Decisions

- Keep the generator entry points focused on orchestration and file output.
- Treat the fixture corpora as named data responsibilities rather than cutting
  either original script at a line boundary.
