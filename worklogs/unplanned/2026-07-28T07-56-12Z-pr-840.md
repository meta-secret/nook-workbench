# Split sync provider store by domain

## Outcome

Squash-merged Nook PR 840. The oversized sync-provider store is now a domain
facade with focused catalog, OAuth, vault-scope, and sync-metadata modules. Unit
tests live inline with the production abstractions they verify, and the external
Rust unit-test file was removed.

## Progress

- Extracted provider catalog and connection policy into `catalog.rs`.
- Extracted OAuth-file credential behavior into `oauth.rs`.
- Extracted vault-scoped provider persistence into `scope.rs`.
- Extracted sync metadata persistence into `sync_metadata.rs`.
- Retained model, enrollment, connection, and replication orchestration in the
  facade.
- Removed `sync_provider_store_tests.rs`.

## Decisions

- Split along provider-store responsibilities, not by line count.
- Preserve the stable public facade while keeping implementation dependencies
  narrow.
- Keep every unit test inline with its owning production module.
