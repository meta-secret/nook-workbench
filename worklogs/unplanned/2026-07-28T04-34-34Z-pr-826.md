# Remove Rust waits from PR preview verification

## Outcome

Squash-merged Nook PR 826. `Verify and preview` no longer waits for Native Rust
coverage or cold-builds the base revision. Three corrected-head measurements
completed preview verification in 3 minutes 31 seconds, 3 minutes 35 seconds,
and 3 minutes 32 seconds, compared with the observed 17 to 20 minute runs.

## Progress

- Moved Rust coverage comparison and reporting into a separate `needs: rust`
  job that directly downloads the current run's native artifact.
- Added an authenticated exact-commit Main artifact resolver that accepts a
  completed Rust artifact while the rest of Main is still running and when a
  later unrelated Main job fails.
- Removed the cold base-coverage Docker fallback. When no trusted base artifact
  exists, the report still enforces the absolute coverage floor.
- Added focused resolver tests for running, failed, expired, and untrusted
  workflow artifacts.
- Updated preflight and all authoritative CI workflow documentation for the new
  producer and consumer topology.

## Implementation problems

- The first run exposed an outdated repository preflight contract. The contract
  was updated to require the independent coverage job and prohibit native
  polling and cold base builds.
- Review found one remaining workflow guide that still described the old native
  wait. The guide and quality contract were synchronized before final delivery.
- Full browser E2E reproduced the same existing vault-flow failures twice. The
  current Main run and earlier Main runs fail the same tests, so the unrelated
  full-E2E label was removed after preserving evidence. The normal exact-head PR
  workflow then passed.

## Decisions

- Preview availability is independent of native coverage completion.
- Coverage artifacts are trusted by workflow identity, event, branch, and exact
  commit rather than the overall Main conclusion.
- An unavailable base comparison must not trigger a second Rust Docker build.

## Validation

- Focused resolver tests passed all four artifact trust cases.
- Repository preflight passed all 56 tests.
- Exact-head PR run
  [30328418259](https://github.com/meta-secret/nook/actions/runs/30328418259)
  passed Native Rust, WASM, Verify and preview, and Rust coverage reporting.
- In the final run, Verify and preview completed in 3 minutes 32 seconds and the
  independent coverage job completed in 21 seconds with no Docker build.
- `task pr:ready PR=826` reported an exact-head deployment, zero unresolved
  review threads, no base drift, and ready state.
- PR 826 was squash-merged as
  `42cf8b5d229c6240dfbe3afaab0f00b95504c71b`.
