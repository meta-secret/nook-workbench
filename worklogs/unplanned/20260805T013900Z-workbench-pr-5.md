# Work summary

## Outcome

[Workbench PR #5](https://github.com/meta-secret/nook-workbench/pull/5) was
squash-merged. Repository-wide record validation is green while current schemas
remain strict for all new and modified records.

## Progress

- Separated reusable record validation from the command-line entrypoint.
- Added an immutable compatibility baseline for 180 exact historical findings
  across 145 content-hashed records.
- Aligned direct-request plans and worklogs with the documented optional issue
  relationship.
- Added behavior-focused validator tests and included them in GitHub validation.
- Protected the compatibility baseline against modification after introduction.

## Implementation problems

- The initial report counted 192 findings. Twelve were false positives caused
  by requiring issue links for direct requests; the remaining 180 are preserved
  as exact historical exemptions.
- The first plan overstated historical statistics scope. A superseding plan
  retained the changed-statistics contract and focused this repair on the
  repository-wide Markdown record validator.

## Decisions

- Historical files remain untouched and exempt only when their SHA-256 content
  hash and exact known finding both match the checked-in baseline.
- New findings on unchanged history, edits to historical content, and invalid
  new records all fail current validation.
- The baseline is introduced once and cannot be updated in a later pull request.
