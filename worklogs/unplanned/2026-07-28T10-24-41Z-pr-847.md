# Split extension service worker domains

## Outcome

Squash-merged Nook PR 847. The former 2,871-line extension service worker is
now a 641-line message router over seven focused runtime modules. Every module
is below 1,000 lines and dependencies flow one way from session lifecycle
through identity and account capabilities into user-operation handlers.

## Progress

- Extracted offscreen session lifecycle and navigation.
- Extracted pairing identity, grants, legacy migration, and origin authorization.
- Extracted account-picker persistence and lookups.
- Extracted login, authenticator, passkey, and pairing-import operations.
- Preserved immediate caller-payload password scrubbing with a sensitive holder.
- Updated the extension setup demo to prove identity discovery routes before the
  pair-intent launcher.

## Decisions

- Keep Chrome runtime listeners and message discrimination in the entry point.
- Keep state with its owning domain rather than a shared global-state module.
- Remove the account/identity cycle by owning unlocked-session classification
  in the lower-level session lifecycle.
- Export only capabilities consumed by another domain or the entry router.
