# Work summary

## Outcome

Merged Nook PR 1068. Nook now treats hierarchical subagent execution as an
event-sourced processing system: every reached agent attempt owns an immutable
JSONL action stream and a bounded semantic Markdown view, parents aggregate
verified child views into higher-level views, and the root delivery owner uses
the verified root view to author the final user report.

## Progress

- Added per-attempt `events.jsonl`, `result.json`, and `view.md` projections
  under the gitignored `workflow/processing/` hierarchy.
- Preserved the run journal as the sole local scheduling authority.
- Added explicit task, agent, attempt, hierarchy depth, and parent lineage to
  every agent event.
- Added all-terminal aggregation so failed lanes retain diagnostic evidence.
- Added the generic `loom:agent-delegation:record` adapter for ordinary coding
  delegation outside compiled static workflows.
- Added the executable `subagent-delegation` skill and synchronized Cortex
  architecture, workflow, references, entry points, and README guidance.

## Implementation problems

- Exact-head review exposed replay paths that originally validated reference
  shapes without proving referenced bytes, complete lineage, authorship, or
  bounded activity details.
- Ordinary Coding Bro delegation originally had no adapter to satisfy the new
  mandatory journal contract outside the Cortex audit graph.
- Later reviews found traversal-capable run IDs, incomplete untrusted result
  decoding, unverified root projections, and unavailable views on executed
  tasks.

## Decisions

- Agents own semantic conclusions and return typed action/result requests.
  Loom owns canonical JSONL serialization, projection persistence, hashing,
  replay validation, and failure views.
- Parents consume verified child views and typed artifact references by
  default. Raw streams are diagnostic evidence, not ordinary context.
- Markdown views are read models and never decide scheduling transitions.
- Every aggregation tier repeats the event-to-view projection until the root
  view. The final user report is the public materialized view of that root.
- The current compiled runtime supports one worker tier plus synthesis. Deeper
  runtime tiers remain rejected until recursive scheduling controls exist.
