# Cross-team expertise and TypeScript ownership

## Outcome

Delivered a matrix ownership model for AI, development core, SRE, and web
development. Functional teams retain capability authority while an explicitly
contracted expert team may implement a bounded unit. General TypeScript
engineering skills now belong to web development and remain available to other
teams through narrow read-only links or explicit expertise contracts.

## Progress

- Defined functional-owner, expertise-provider, and delivery-owner boundaries.
- Added strict selective-context rules for team agents and foreign-team policy.
- Moved five general TypeScript skills from shared Cortex to web development.
- Updated team graphs, executable skill mirrors, prompts, workflows, and Loom
  references to use the canonical ownership paths.
- Added machine-enforced ownership-unit validation for multiple capabilities,
  exact delegated paths, forbidden-path overlap, interfaces, and evidence.
- Added Workbench and Rust preflight regression coverage.
- Squash-merged Nook PR 1165.

## Implementation problems

- Early policy drafts did not distinguish direct read-only skill consumption
  from delegated implementation. The contract now supports both explicitly.
- Review exposed missing enforcement for multiple linked skills, exact paths,
  canonical routing, SRE TypeScript discoverability, and nested allowed versus
  forbidden path overlap. Each gap was fixed and covered by tests.
- Hosted Codex review exceeded its bounded wait. Delivery continued under the
  repository policy after iterative local advisory review reached a clean
  result.

## Decisions

- Capability semantics, Cortex authority, integration, and final acceptance
  remain with the functional owner.
- Expertise delegation grants only the exact code and test paths frozen in the
  ownership unit. It never grants foreign Cortex ownership.
- A team may consume a directly linked foreign skill as read-only policy
  without invoking an expertise provider.
- General TypeScript engineering policy belongs to web development. AI retains
  ownership of Cortex, Loom, and AI capability semantics.
