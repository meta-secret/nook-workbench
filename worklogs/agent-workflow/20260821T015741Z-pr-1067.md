## Decisions

- Cortex remains the owner of semantic policy and judgment. Loom owns typed
  deterministic leaves and reviewed static graph topology.
- Markdown, YAML, prompts, session notes, and model output never become
  executable Loom topology at runtime.
- Parallel semantic work requires one immutable baseline, non-overlapping
  resources, independent evidence, and a parent-defined join.
- Session cleanup is runtime mechanics owned by Loom, not a GitHub Actions
  script or an executable skill wrapper.
