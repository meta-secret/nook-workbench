# Deterministic bounded subagent orchestration

## Outcome

Defined and merged Nook's delegation policy and agent-workflow architecture. Cortex now requires bounded delegation when two or more independently verifiable work units have explicit ownership and a defined join. Loom is the selected deterministic workflow engine. Lace remains experimental and is slated for removal rather than extension.

## Progress

- Audited Cortex workflows, dynamic skills, architecture docs, Loom, Minds, Lace, and Hive with three read-only specialist workers.
- Added the canonical subagent-delegation workflow and the agent-workflow orchestration design document.
- Defined one delivery owner, disposable bounded workers, immutable baselines, typed results, resource ownership, ready-wave scheduling, retries, cancellation, and parent-owned integration.
- Documented the staged path from Loom manifest validation to Codex SDK execution and later durable Hive task execution.
- Updated Cortex indexes and the Loom, Minds, and Hive runtime boundaries.
- Merged Nook PR #998.

## Implementation problems

- Lace exposes only prototype graph fixtures and no working orchestration runtime. The design therefore retires Lace and places the new capability in Loom.
- The first normal squash-merge command was rejected because the repository ruleset requires a successful `github-pages` deployment while Cortex and agentic-AI-only changes are intentionally excluded from the product preview workflow. Auto-merge could not satisfy a deployment that the path policy does not create. The repository readiness audit was clean, so the PR was merged through the administrator path without fabricating a deployment.

## Decisions

- Markdown owns semantic policy, worker contracts, acceptance evidence, and judgment. It does not pretend to schedule work.
- Loom will gain a typed `agentWorkflow` family for graph validation, deterministic scheduling, structured artifacts, retries, cancellation, and Codex SDK worker execution.
- Hive retains one task, one Pod, and one Codex thread. Future durable graphs map nodes to separate Hive tasks instead of enabling nested workers inside a Hive thread.
- Delegation is mandatory only for at least two independent semantic work units. Mechanical commands, tightly coupled edits, shared lifecycle mutations, and small cohesive fixes remain deterministic or single-owner work.
- The first implementation pilot is a read-only Cortex semantic audit. Write-capable workflows follow only after the scheduler and worker adapter prove isolation and cancellation.
