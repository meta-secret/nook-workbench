# Isolate Loom agent-statistics temporary paths

## Outcome

PR 1035 replaced collision-prone fixed temporary examples with a portable
Loom token. The token resolves to an agent-owned directory containing a stable
task-anchor commit and an opaque worktree identifier.

## Progress

- Audited committed YAML and Cortex examples for shared writable paths.
- Added token resolution for assemble, validate, and publish path fields.
- Made toolsList return explicit authored and resolved YAML for every request.
- Preserved all Cortex relationship sections and document maps.
- Added regressions for parallel worktrees, implementation commits, branch
  re-entry, and branches created directly with a worktree.
- Replied to and resolved all six review conversations after fixes were visible.

## Implementation problems

- Current-HEAD path identity moved after implementation commits. The final
  design uses the first task-branch entry, or the worktree's initial commit.
- The initial branch-entry lookup did not cover direct worktree branch creation
  or later branch re-entry. Both reflog shapes now have regressions.
- GitHub API quota delayed the first hosted dispatch.
- Main advanced during hosted validation, requiring a fresh-base merge and a
  replacement exact-head run.

## Decisions

- Keep relationships and document maps in Markdown as agent context.
- Limit dynamic path support to the agent-statistics fields that owned unsafe
  fixed examples.
- Keep ordinary absolute and relative paths compatible.
- Provision the agent-owned directory during token resolution.
- Use the same resolved YAML field for static and tokenized requests so state
  remains explicit.

## Validation

- Loom formatting, TypeScript checks, lint, and 135 unit tests passed.
- Focused path and codec tests passed with 18 cases and 76 assertions.
- Cortex audit passed with no link, index, density, or structure findings.
- Exact macOS mktemp allocation and toolsList path resolution were verified.
- Hosted preflight run 31974746303 passed on the final head.
- Readiness reported a fresh base, mergeability, and zero unresolved threads.
- PR 1035 squash-merged as 7dd7704cd4e0870bf424c8cb7eceb2a2a3055280.
