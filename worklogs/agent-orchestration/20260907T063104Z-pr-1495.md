# Reactive PR pipeline end-to-end canary

## Outcome

Created and completed PR #1495 as a real end-to-end canary. A natural GitHub
`pull_request.synchronize` delivery traversed the existing webhook, Argo
EventSource, EventBus/NATS subject, PR-specific Steward subscription, and
Steward-to-Gizmo message boundary. Gizmo then drove bounded validation and
merge operations, received the terminal `pull_request.closed` event, reconciled
GitHub once, and stopped the subscription cleanly.

## Progress

- Opened the PR with a 10-line first-phase workflow clarification.
- Started a direct subscriber scoped immutably to PR #1495 and observed no
  child process or network connection other than WSS port 443.
- Pushed a natural synchronization commit while the subscriber was connected.
- Correlated delivery `197a28f0-aa83-11f1-8a94-77acb471640c` from GitHub through
  Argo event `bec7da3b2bd540eb9caeab1ade1d5e63` to the Steward notification.
- Used NATS workflow/check notifications to decide when to perform bounded
  GitHub reconciliation; no continuous GitHub polling was introduced.
- Merged the PR, received terminal delivery
  `58e5e630-aa85-11f1-8b9a-1399b1111c9a`, reconciled final state, and drained
  subscriber session 4569.

## Implementation problems

- The first Steward used an overlong blocking terminal read. NATS delivered the
  event to its PTY, but the AI child did not regain a reasoning boundary to
  notify Gizmo. Gizmo stopped that process, and the AI owner updated the
  workflow to require PTY/NATS reads of at most five seconds with a return to
  reasoning after every read.
- The replacement Luna Steward notified Gizmo immediately after connecting and
  reported the next synchronization event in the same UTC second as Argo
  publication.
- The first ordinary squash attempt was rejected by branch policy. After a
  fresh successful readiness check, Gizmo separately authorized the documented
  admin-squash route; the second and final merge attempt succeeded.

## Decisions

- Poll only the local foreground PTY/NATS stream in bounded intervals; never
  poll GitHub while waiting for events.
- Treat NATS events as prompts for bounded PR Steward operations, while direct
  GitHub reconciliation remains authoritative at validation and completion
  boundaries.
- Keep the subscription alive through merge so the terminal closed event is
  observable, then let Gizmo explicitly command shutdown.
