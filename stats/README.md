# Statistics

This directory contains delivery measurements generated by work in
[`meta-secret/nook`](https://github.com/meta-secret/nook).

- `ai-agent/` records one completed Nook implementation PR per YAML file.
- `main-build/` records one completed Nook Main workflow attempt per YAML file.

The schema and analysis rules are owned by Nook's
`.cortex/workflows/agent-statistics.md` and
`.cortex/workflows/main-build-statistics.md`. Statistics are committed here so
they do not create bookkeeping pull requests or product workflow noise in the
source repository.
