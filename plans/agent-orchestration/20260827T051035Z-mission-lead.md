# Define the Mission Lead Coordination Role

## Interpreted request

Make the root agent contract state that one coordinating agent owns mission
decomposition, delegation, observation, acceptance, and correction loops. Team
agents own implementation. The coordinating role needs a concise name.

## Requirements

- Name the coordinating role **Mission Lead**.
- State that the Mission Lead delegates implementation to bounded team agents.
- State that the Mission Lead observes the complete mission and integrates
  accepted results.
- State that insufficient results return to the responsible team agent until
  the requested outcome is complete.
- Preserve team ownership, isolated scope, and shared lifecycle boundaries.
