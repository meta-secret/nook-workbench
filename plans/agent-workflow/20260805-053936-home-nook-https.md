# Task plan

## Interpreted request

Move trusted local development HTTPS certificate material from a
checkout-scoped directory into the shared home Nook config directory so every
git worktree reuses one CA and one localhost certificate set.

## Requirements

- Generate and trust mkcert material under the home Nook HTTPS directory.
- Mount that shared directory into local web-dev containers.
- Point Vite HTTPS env paths at the mounted shared material.
- Prefer a one-time copy from any leftover checkout-scoped certs before minting
  a new CA.
- Document the home path and keep machine-local credentials/config out of the
  repository checkout.
- Add a preflight contract so the home-only HTTPS path does not regress.

- Keep release-workflow checkout material under the repository `.nook` path.
- Do not open a PR or run complete hosted validation in this slice unless the
  surrounding Docker split work is ready.
- No change to production TLS or Playwright loopback HTTP transport.
