# Define bounded subagent orchestration policy

## Interpreted request

Establish a durable Nook policy for bounded child workers. Expand Loom from
mechanical rites into the single deterministic local workflow engine and retire
the experimental graph fixture.

## Requirements

- Define a mandatory delegation threshold based on independence and ownership.
- Keep one delivery owner responsible for integration and external mutations.
- Add an `agentWorkflow` capability to Loom in later implementation slices.
- Use the Codex SDK for local worker threads after an authentication spike.
- Describe Hive as the later durable adapter with one task per worker.
- Delete Lace after Loom owns the typed graph contract.

## Constraints and exclusions

- Do not enable concurrent writes in one shared worktree.
- Do not delegate Workbench, branch, pull-request, review, or merge mutations.
- Do not implement the Loom workflow engine in this documentation slice.
- Do not retain the experimental graph behavior as a compatibility surface.
