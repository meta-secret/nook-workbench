# Separate finite loader proofs into a ten-slice executable skill stack

## Interpreted request

the 5,000-line PR limit before it could soundly prove an existing companion
loader. Preserve strict fail-closed reachability while giving finite loader and
generated-artifact provenance their own reviewable predecessor.

## Requirements

- Keep every immediate-base PR below 5,000 changed lines and every authored
  source file at or below 1,000 lines with meaningful correction headroom.
- Keep bounded loader specialization and artifact provenance separate from
  subprocess, workflow, action, and runnable-script graph traversal.
- Reject arbitrary dynamic loaders, caller-controlled paths, missing producers,
  sibling artifacts, and repository-backed package aliases.
- Apply the resulting proof only through reviewed static TypeScript tests until
  final activation.
- Replay every successor on the exact accepted predecessor and prove patch
  equivalence for already reviewed behavior.

- No dormant skill implementation may execute through production Loom.
- The companion loader remains fail-closed until a finite capability proof or
  an owned production refactor is accepted.
- Published plans remain immutable; this plan supersedes the nine-slice record.
