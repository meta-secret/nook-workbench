# Define Cortex structured-article contract and enforcement

## Interpreted request

Bring one transparent hierarchical structure to the body of the entire Cortex
documentation corpus. Use lists, nested lists, ordered procedures, and headings
where they expose the real shape of instructions. Preserve detailed explanation
where prose is the clearer representation.

## Requirements

- Establish a universal semantic article grammar before mass rewriting.
- Make action order, conditional branches, validation, and failure handling
  visually explicit.
- Keep rationale and tradeoff prose readable inside clearly owned sections.
- Integrate the rule with document maps and existing Cortex writing guidance.
- Add syntax-aware mechanical enforcement for provable structural properties.
- Migrate all 83 documents through bounded PRs.

## Constraints and exclusions

- Do not enforce an arbitrary ratio of prose to lists.
- Do not turn every paragraph label into a heading.
- Do not change product, architecture, security, or workflow meaning while
  restructuring documentation.
- Keep every Nook PR below 5,000 authored changed lines.
- Publish public-safe plans, worklogs, and delivery statistics for each PR.

## Initial plan

1. Inventory body shapes and identify mechanically provable invariants.
2. Deliver a foundation PR with the contract, executable skill, AST audit,
   fixtures, and migration ledger.
3. Migrate dynamic skills A/B, workflows A/B, design A/B, product A/B,
   references plus execution plans, and root documents.
4. Regroup each slice by measured authored diff before publication.
5. Keep each PR below the hard line limit.
6. Finish with a semantic audit, ledger removal, and global enforcement.

The estimated migration is 28,000-38,000 authored changed lines across 10-12
PRs. The owning layer is `.cortex` plus the Loom Cortex audit. The public
interface is the Cortex article grammar and agent reading contract.

## Completion evidence

- Every Cortex document follows the structured-article grammar.
- Procedures expose ordered actions and nested conditions.
- Parallel rules and choices use clear list hierarchy.
- Long-form explanation remains semantically accurate and readable.
- Loom and semantic audits pass with no migration ledger.

## Safety review

- This work restructures public-safe project documentation only.
- It records no prompt transcripts, secrets, private data, raw logs, or local
  machine paths.
